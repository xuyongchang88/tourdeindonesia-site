# PT Tourdeindonesia (TDI) Health Industry Website

Static website for `tourdeindonesia.com`.

## Pages / Sections

- Home hero
- Event Services
  - Indonesia 9-Ball International Open & Branch Events
  - International Road Invitationals & Stage Events
- Products
  - Billiard cloth
  - Certified cue series
  - Commemorative cue series
  - Cultural & lifestyle goods
- Trust system
- News & case library
- Contact

## Languages

Built-in front-end language switcher:

- Indonesian (`ID`)
- English (`EN`)
- Traditional Chinese (`繁`)

## Deployment

Upload the entire `tourdeindonesia-site` folder contents to any static host:

- GitHub Pages
- Cloudflare Pages
- Netlify
- Nginx / Apache server

Entry file: `index.html`.
